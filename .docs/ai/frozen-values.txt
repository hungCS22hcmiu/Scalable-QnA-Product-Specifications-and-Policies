# Patterns the frozen-guard hook greps against proposed file content.
# A match means the edit MAY be touching a frozen experimental value (rules.md #1).
# The hook blocks unless the active task's approvals.md cites an ADR.
#
# Format: one extended-regex per line. Patterns MUST match an ASSIGNMENT (name = value),
# not a bare identifier — a parameter or struct field named top_k is a declaration, not a
# change, and matching it produces constant false positives that train you to ignore the guard. Lines starting with # and blank lines ignored.
# Keep this list tight — every false positive costs a real interruption.
#
# Governing: interfaces.md "Frozen study-wide" · experiment-protocol.md §1 · decisions.md
