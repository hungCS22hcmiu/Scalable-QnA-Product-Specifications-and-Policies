# Design review — answer-text-storage

**Reviewer:** `design-reviewer` subagent (opus), against `spec.md` rev 2, `impact.md` and `design.md`
rev 2 and the code. **Verdict: sound; approve once finding 1 is fixed.** It found no production path
that leaves a wrong-content file under a hash name. Its real catch is that the **binding exit test
could not fail on two of the mutations it claimed to catch.**

Four of its factual claims were re-checked by hand before acting (✔︎): the fixtures share one text
(finding 1), Spotlight indexes `/` (9), the `:487` label (10), `AnswerChunk.text` is a proto3
`string` (17). The rest is its reading, with its citations.

## What the review says the design gets right

Ordering is structural (a dropped or post-`Close` record loses its line and its file together, so
"file before line" holds for every line in an admissible run); the guard **after** the `seen` check
is safe (a record skipped by `seen` names a hash whose file a guarded record already published); the
invariant is stated on the record so a MISS whose client left is covered and hits write too; `Link`
over `Rename`, temp names not ending in `.txt`, the `Chmod`; `Open`'s `O_EXCL`-first-then-leaf-`Mkdir`
(a crash between the steps burns the run id and leaves no directory a later run could inherit);
`seen` set only on success and `missing` tracking current state; `""` versus empty text pinned;
nothing added to the hit path; the U8 reading; publication left to the author; `incomplete()`
covering the old, never-run `Dropped` branch.

## Questions the review puts to the author (carried to `approvals.md`)

1. `answers/` directory or `answers.jsonl`? 2. Keep D3, and should the `Close` error join
`incomplete()` (**adopted by default**)? 3. Publication: ignore `experiments/results/*/raw/` now,
and which item gates the first v1 run on that? 4. Should a **guard refusal void a run**, or only be
asserted 0 in tests (**default: it voids the run**: it means a call site skipped `SetAnswer`, which
is a defect that invalidates the measurement and would otherwise be cleared by a later retry).
5. Persist the INCOMPLETE counts into `raw/` before P1? (**No**: that is the manifest, 1.6.)
6. Is 5.1's verdict key `(query, answer)`? 7. Spotlight exclusion as a run precondition?
